Proceed — 6 high-value gaps, phased over 3 sprints
Snowball's portfolio has strong analysis depth. trefolio matches most of it, but 6 gaps meaningfully impact retention and Pro conversion.
Why Proceed
  • Diversification tab — Snowball's sector/region breakdown in a dedicated tab is richer than trefolio's tools-buried taxonomy view. Primary users (5–50 holdings) want this front-and-center.
  • Portfolio metrics tab — Snowball shows TTWROR, Max Drawdown, Sharpe Ratio, Volatility in one screen. trefolio has TTWROR/IRR but buries them in Tools.
  • Income tab — Snowball has a dedicated income view (monthly bars, dividend income vs. capital gains). trefolio's dividend summary is comparable but not surfaced as a first-class tab.
  • Public portfolio sharing — Snowball's entire brand revolves around shareable portfolios. This is a viral growth lever trefolio doesn't have.
  • Ex-dividend calendar — Missing in trefolio. Dividend investors rely on this heavily.
  • Stealth mode — Snowball lets users hide money values for screenshots/screencasts. Low effort, high shareability.
Out of Scope / De-prioritized
  • SnapTrade broker sync — Adds a third-party data processor (legal review required); trefolio already covers DEGIRO, IBKR, T212, Revolut. Not worth compliance overhead now.
  • Community / social feed — Snowball has a public portfolio list with social following. Building a social graph is a 6–12 month undertaking; defer to roadmap post-v2.
  • EODHD data integration — Snowball uses EODHD for fundamentals. trefolio uses Alpha Vantage (Pro). Adding another data provider creates maintenance cost without net-new user value.
  • Growth tab (portfolio history chart) — trefolio has benchmark chart and projections. Full historical growth line requires storing daily NAV snapshots; non-trivial schema change. Phase 2.
  • Transaction-level P&L per holding — Snowball's Transactions tab shows "total profit" per transaction row. trefolio shows aggregate P&L. Nice-to-have, Phase 3.
Tier Fit
  • Free: Diversification tab, Metrics tab, Stealth mode, Ex-dividend calendar
  • Pro: Public portfolio sharing (viral + Pro paywall), Portfolio history (daily NAV), Transaction P&L detail
Primary Segment Fit
  • Beginner–intermediate retail investor (5–50 holdings) ✓
  • Dividend-focused European investors ✓
  • Expats managing multi-currency portfolios ✓
  • Social/community investors — currently secondary

Implementation Roadmap

Three phases ordered by user impact and implementation dependency. Each phase is independently shippable.

1
Dashboard Navigation Restructure + Stealth Mode
Promote hidden features to first-class tabs; add viral sharing hook
~1 SPRINT · FREE TIER
▾
📊
Diversification tab in main dashboard nav
Move TaxonomyView (sector/region/asset class donuts + rebalancing) from Tools into a prominent "Diversification" tab on the main dashboard. Tab should be first-class alongside Portfolio, News.
Free Low effort
💰
Dividends/Income tab in main dashboard nav
Promote DividendSummary to a "Dividends" tab. Add Income sub-view: monthly income bar chart split by dividends received vs. net capital gains (realized P&L from sell transactions).
Free Low effort
📅
Ex-dividend calendar
For each holding in the portfolio, fetch upcoming ex-dividend dates from Alpha Vantage. Display in a calendar/list view in the Dividends tab. Shows ticker, amount, ex-date, pay date. Replaces the current "upcoming" placeholder.
Free Med effort
🎭
Stealth mode toggle
Global toggle (accessible from nav bar) that replaces all monetary values with "•••••" using a React context. Persisted to localStorage. Shows a banner while active. Highly shareable screenshots = organic growth.
Free Low effort
2
Advanced Metrics Tab + Portfolio History
Close the risk analytics gap; add daily NAV tracking for growth chart
~2 SPRINTS · PRO TIER
▾
📐
Metrics tab — Sharpe Ratio, Max Drawdown, Volatility, Beta
New "Metrics" dashboard tab. Expands on existing TTWROR/IRR (Tools → Performance) with: Sharpe Ratio (requires risk-free rate, e.g. ECB rate), Max Drawdown from peak, Annualized Volatility (std dev of daily returns), Beta vs benchmark. All calculated client-side from transaction + price history data. Gate behind Pro.
Pro Med effort
📈
Portfolio history / Growth chart (daily NAV snapshot)
Store a daily snapshot of portfolio total value in a new portfolio_snapshots table. Display as an absolute value area chart in a "Growth" tab. Time range selector (1M, 3M, 6M, 1Y, All). Requires a cron job or on-login trigger to record NAV. Pro feature — longer history window (Free: 30 days, Pro: unlimited).
Pro High effort Schema migration
3
Public Portfolio Sharing + Transaction P&L
Viral growth lever + transaction detail parity
~2 SPRINTS · PRO TIER
▾
🔗
Public portfolio sharing
Pro users can generate a public share link (/p/[token]) that renders a read-only version of their portfolio with configurable privacy (show/hide values, exclude specific holdings). Stealth mode defaults to on for shared portfolios. This is trefolio's equivalent of Snowball's entire public portfolio feature — a top Pro upgrade incentive.
Pro High effort
🧾
Transaction-level realized P&L (FIFO)
Add a "Total profit" column to the transaction table showing realized gain/loss per sell transaction using FIFO lot matching. Calculated on-the-fly from transaction history. Improves tax reporting use case.
Free Med effort

Success Metrics & Instrumentation

How we measure whether these features are working. Track at launch and review at 30/60/90 days.

Phase 1 — Primary Metrics
  • Diversification tab CTR — % of DAU who click the new tab within first session. Target: ≥40%
  • Dividends tab CTR — same. Target: ≥35% for portfolios with dividend holdings
  • Stealth mode activation rate — % of users who toggle it on at least once. Target: ≥15%. High = users are screenshot-sharing.
  • Ex-dividend calendar views — impressions per user per week. Target: ≥2/week for div portfolios
Phase 2–3 — Primary Metrics
  • Metrics tab → Pro upgrade CTR — clicks on locked metric → upgrade. Target: ≥8% of users who see the lock
  • Public portfolio shares created — count of share links generated per week. Target: ≥50/week at 90 days
  • Inbound from shared links — new signups from /p/[token] referral links. This is the primary viral coefficient.
  • Growth chart engagement — time on Growth tab, range selector interactions

Legal Compliance Notes
  • Public portfolio sharing — users sharing financial data publicly: review legal-advisor skill before implementation. Ensure disclaimer is displayed on all public portfolio pages (financial data ≠ investment advice).
  • Ex-dividend calendar — displays financial data; existing disclaimer covers this under the current terms of service. No additional legal review needed.
  • Stealth mode / Metrics / Diversification tab — no new data collected, no new 3rd-party requests. No legal review required.
