Acciones primarias en el chrome

Buscar, Importar, Alertas y Añadir viven en el header (siempre visibles). La navegación de destinos (Home, Portfolio, Tools, Discover) baja a una franja secundaria. En mobile: dock con FAB central de alta.

Alta de assets

  1. Importar (CSV / broker / AI)
  2. Buscar asset → add
  3. Añadir manual (stock/fund/crypto)
  4. Warren “add stock” (empty)

Evaluar portfolio

  1. Home (pulse diario)
  2. Alertas (triggered)
  3. Portfolio performance
  4. Tools / allocation / holdings

Screening / descubrir

  1. Screener
  2. Moat / screening
  3. Company analysis
  4. Explore / digests

Qué resuelve A

  • Las 4 herramientas de alta/monitoreo no compiten con destinos.
  • Search es el ancla del header (comando único).
  • Mobile FAB = sheet: Importar · Buscar · Añadir manual.
  • Alertas sale de Tools y gana badge en chrome.
  • Screener/Moat suben a 1 tap (desktop) o Discover (mobile).
Trade-off: header más denso en desktop; en mobile el dock pierde un slot de “Tools” genérico a favor de Alertas + Discover.
