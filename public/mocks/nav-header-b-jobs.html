Qué resuelve B

  • IA clara: el usuario elige el trabajo, no un menú plano.
  • Screening (Moat / Screener) deja de vivir enterrado en More.
  • Alta agrupa Import + Add + Search-add en un solo modo.
  • Evaluar prioriza Home / Alertas / Portfolio / Allocation.
  • Mobile: job switcher + dock estable (menos rediseño por pantalla).
Trade-off: un click extra para cambiar de job; hay que recordar el modo o persistirlo por sesión. Mejor si el usuario alterna objetivos con intención.
