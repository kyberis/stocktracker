# Device Firmware Engineer

## Scope

Own the T4-S3 hardware firmware, LVGL display UI, API client, and desktop simulator.

## Hardware

- **Board**: LILYGO T4-S3 — ESP32-S3 @ 240 MHz, 16 MB QIO flash, OPI PSRAM
- **Display**: 2.41" AMOLED, 600x450, capacitive touch
- **Connection**: USB-C (CDC on boot for serial + built-in JTAG)
- **Library**: `LilyGo-AMOLED-Series` — auto-detects board via `amoled.begin()`
- **Graphics**: LVGL 8.4.0 (bundled with the LilyGo library on device, standalone for simulator)

## Primary Files

```
lilygo-t4s3/
  platformio.ini            -- device + simulator environments
  simulator/lv_conf.h       -- LVGL config for SDL2 simulator (32-bit color)
  src/main.cpp              -- device entry (Arduino setup/loop), WiFi, boot flow
  src/sim_main.cpp          -- simulator entry (SDL2 main loop, #ifdef SIMULATOR)
  src/ui.h / ui.cpp         -- all LVGL screens: token entry, dashboard, loading, error
  src/stocks.h / stocks.cpp -- PortfolioData struct, parsed from API JSON
  src/api_client.h / .cpp   -- HTTPS client for /api/portfolio/summary and /api/device/ai-summary
  src/config.h / .cpp       -- WiFi credentials (hardcoded), NVS token storage (Preferences)
```

## PlatformIO Environments

| Environment | Platform | Framework | Purpose |
|---|---|---|---|
| `lilygo-t4-s3` | espressif32 | Arduino | Device build; excludes `sim_*.cpp` |
| `simulator` | native | — | SDL2 desktop build; excludes `main.cpp` |

Platform-independent code uses `#ifdef SIMULATOR` guards. The simulator uses 32-bit color (`LV_COLOR_DEPTH 32`) vs device 16-bit (`LV_COLOR_DEPTH 16`, `LV_COLOR_16_SWAP 1`).

## Build Commands

- Device build: `pio run -e lilygo-t4-s3`
- Flash: `pio run --target upload`
- Monitor: `pio device monitor`
- Simulator build: `pio run -e simulator`
- Simulator run: `.pio/build/simulator/program`
- Debug (device): F5 in Cursor (uses built-in ESP32-S3 JTAG)

## LVGL 8.4 Conventions

### Fonts (all Montserrat sizes 12–48 enabled)

| Use | Font |
|---|---|
| Portfolio total value | `lv_font_montserrat_30` |
| Large section values | `lv_font_montserrat_20` |
| Brand / titles | `lv_font_montserrat_16` |
| Body / tickers | `lv_font_montserrat_14` |
| Labels / secondary | `lv_font_montserrat_12` |

### Card Styling

- Background: `COL_SURFACE` (`#1e293b`)
- Border: `COL_BORDER` (`#334155`), 1px width
- Radius: **16px** (matching web's `rounded-2xl`)
- Use the `make_card()` helper for consistent styling
- Day change displayed as a **pill badge** with translucent gain/loss background
- AI card uses `COL_ACCENT2` (violet) border with icon circle

### Color Palette (matches trefolio web dark theme)

### Screen Patterns

- Create screens with `lv_obj_create(nullptr)` and apply `style_black_bg()` (uses `COL_BG` = slate-900)
- Transition between screens with `lv_scr_load_anim(scr, LV_SCR_LOAD_ANIM_MOVE_LEFT, 250, 0, false)`
- Use flex layout via `lv_obj_set_flex_flow(obj, LV_FLEX_FLOW_COLUMN)`
- Use `lv_disp_get_hor_res(nullptr)` / `lv_disp_get_ver_res(nullptr)` for adaptive sizing
- Dark theme applied globally in `ui_init()` via `lv_theme_default_init(..., true, ...)`
- Brand shown as **"trefolio"** (lowercase) with emerald accent color
- Design mockup available at `lilygo-t4s3/mockup-redesign.html` for visual reference

## API Integration

### Authentication

Uses a **device passkey** — 8 numeric digits displayed as `XXXX-XXXX`. Passkey is:
- Generated by the user in the web profile page ("Device Passkey" section)
- Stored hashed (SHA-256) in the `device_passkey_hash` column of the users table
- Entered on the device via a custom numeric touch keypad
- Stored on device in ESP32 NVS via the Preferences library
- Sent as `Authorization: Bearer XXXX-XXXX` header on every API call
- Backend also accepts the legacy `tfw_` widget token format

### Endpoints

| Endpoint | Method | Auth | Returns |
|---|---|---|---|
| `/api/portfolio/summary` | GET | Bearer token | `totalValueEUR`, `costBasis`, `dayChangeEUR`, `dayChangePercent`, `totalGainLoss`, `totalGainLossPercent`, `holdingsCount`, `topHoldings[]` |
| `/api/device/ai-summary` | POST | Bearer token (Pro) | `{ summary: "..." }` — condensed 200-word portfolio AI review |

### topHoldings shape

```json
[{ "ticker": "AAPL", "name": "Apple Inc.", "weight": 32.1, "dayChange": 1.2 }]
```

## Key Dependencies

- `LilyGo-AMOLED-Series` (git) — display, touch, board drivers
- `bblanchon/ArduinoJson@^7` — JSON parsing for API responses
- `WiFi`, `HTTPClient`, `WiFiClientSecure` — built into ESP32 Arduino
- `Preferences` — built-in NVS key-value storage
- `lvgl/lvgl@~8.4.0` — standalone LVGL for simulator only
