Design decisions:
• Quotes use absolute time (HH:MM:SS) — consistent with existing lastUpdated pattern in toolbar.
• Holdings use relative time ("just now", "5m ago") — consistent with BrokerSyncDot in PortfolioSummary.
• Green dot = fresh (< 30 min). Yellow dot + yellow text = stale (≥ 30 min).
• Cluster hides entirely if both timestamps are null (initial load before any fetch completes).
• Hidden on mobile (hidden sm:flex) — toolbar already uses this pattern for lastUpdated.
• No new API calls or DB schema changes — holdingsLastFetchedAt is in-memory only.
