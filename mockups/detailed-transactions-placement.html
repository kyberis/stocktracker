Placement Proposal

Where to Show "Upgrade Your Data" Nudges

  • 6 placement locations across the product, each triggered by specific data quality conditions
  • Contextual, not nagging — nudges appear exactly where incomplete data affects the user's experience
  • Progressive disclosure — from soft hints to explicit CTAs depending on severity
  • User journey — nudges appear at the moment the user feels the pain of missing data

Design Principles
🎯
Contextual, not global
Each nudge appears only on the screen where incomplete data actually causes a problem. No generic "import more data" nag bars.
🔇
Dismissible, not annoying
Every nudge can be dismissed. High-value screens (Tax, Dividends) reset per session. Lower-value ones (Dashboard) stay dismissed permanently.
📐
Consistent visual system
Amber = data quality warning. Blue = informational. Emerald = opportunity. Violet = upsell moment. Same icon + title + desc + CTA pattern everywhere.
