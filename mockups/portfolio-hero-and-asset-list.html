Key changes

  1. Invested vs cash split
    Headline becomes totalCurrentEUR − Σ cash. Idle cash gets its own row with an Invest CTA. Net worth moves to a tooltip.
  2. Corrected day-% denominator
    dayGainLoss / investedEUR replaces the current formula that inflates the denominator by cash.
  3. One-line holding row
    Collapses name + exchange | ticker | price × shares into a four-column grid: name · sparkline · value · return.
  4. Quieter chrome
    Day change demoted from boxed pill to inline triangle + color. Quote freshness moves inline. Sort carets on column headers (desktop).
  5. Segmented asset filter
    All now means all assets, not assets + cash — the label matches the new invested headline.
  6. Slim deep-dive CTA
    Single slim row with right-aligned arrow, not a dashed-border button block. Expands the existing chart unchanged.
