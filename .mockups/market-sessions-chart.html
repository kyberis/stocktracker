Design Decisions & Interactions

1 Session Background Bands

Subtle colored bands show when each market is in session. XETRA = blue, NYSE = green. Colors come from the existing market status system. Opacity is very low (6%) to avoid competing with the chart line — increases to 12% on hover.

2 Open/Close Dashed Lines

Vertical dashed lines mark the exact open (green) and close (red, faded) times. Small labels at the top show market name + time. Only shown on 1D view where intraday precision matters.

3 Tooltip Enhancement

The existing tooltip gains a new "market session" section at the bottom showing which markets are open at the hovered time, with a green/red dot and how long until they close. Reuses the existing getMarketStatus() logic.

4 Range-Adaptive Display

1D: Full session bands + open/close markers + tooltip sessions.
1W: Trading day bands + weekend gaps (labeled "WEEKEND").
1M+: Only weekend bands as thin gray strips. Tooltip still shows market status. This avoids visual clutter on wider time ranges.

5 Session Legend

A compact legend below the chart identifies each market's color. Only shows markets that the user's portfolio actually trades on (derived from holding exchanges). Auto-hides when only one market or when range > 1M.

6 Data Source

Market open/close times come from the existing market-hours.ts module which already maps every exchange code to schedules. No new API calls needed — times are computed client-side from holdings' exchange codes and converted to the user's local timezone.
