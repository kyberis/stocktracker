Design notes:
  • Asset filter pills — toggle between All (stacked area, all types overlaid) or a single asset type (isolated area chart). Clicking a breakdown card also filters.
  • Value / Performance toggle — "Value" shows absolute €, "Performance" shows % return (rebased to 0%).
  • Breakdown cards — always visible below the chart; show value, daily + total P&L, and allocation bar per type.
  • Performance table — optional section with key risk/return metrics per asset type and configurable period.
  • "All" stacked view uses a stacked area chart so users see how each type contributes to total value over time.
  • The hero value and change badges update to reflect the selected filter (e.g., filtering to "Crypto" shows only crypto totals).
  • Mobile: breakdown cards stack vertically; chart height reduces; pills scroll horizontally.
