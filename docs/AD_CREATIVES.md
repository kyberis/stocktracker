---

## Production Workflow

1. Open `docs/ad-creatives-gallery.html` in a browser
2. Each creative renders at 1200×628 (2x for retina)
3. Right-click → "Save image as" or use a screenshot tool at the exact dimensions
4. Upload to Meta Ads Manager with the corresponding copy from this document
5. Use the UTM links above as the destination URL for each ad
