Design Notes

  • Color coding: emerald = Earnings, violet = Economic, amber = IPO — consistent across dots, indicators, and badges
  • Portfolio highlight: Sky-blue "In Portfolio" badge with star icon on earnings for user's own holdings
  • Tier gating: Blurred content + centered overlay with upgrade CTA. Economic = Bifolio gate, IPO = Trefolio gate
  • Free tier: Earnings list always visible (only portfolio holdings for free users; all earnings for Bifolio+)
  • Views: Calendar (month grid) as default, List view as toggle. Both share the same data
  • Mobile: Calendar grid compresses; events list stacks below (single column). Stats row wraps to 3 cols
  • Impact levels: Red dot = High, Amber = Medium, Emerald = Low — for economic events
  • Data layout: Earnings show ticker + company + Est. EPS + timing (BMO/AMC). Economic show prev/forecast/actual. IPO show price range + exchange
  • Design system compliance: Uses --surface (#1e293b) for cards, rounded-2xl (16px), pill selectors, and the standard dashboard tab bar pattern
