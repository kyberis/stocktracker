Implementation Notes

Spotlight Positioning

Each step targets a DOM element by data-tour attribute (e.g. data-tour="nav"). The component uses getBoundingClientRect() to position the spotlight hole and the tooltip. A ResizeObserver keeps it in sync on resize.

Smooth Transitions

The spotlight hole animates between steps with a 400ms cubic-bezier transition. The tooltip fades out and back in on each step change. On mobile, the bottom sheet slides between content without unmounting.

Persistence

Key: trefolio_seen_themes. Value: JSON array of theme IDs. "Finish tour" or completing all steps appends the theme. "Skip tour" also marks the current theme as seen.

Scroll-Into-View

Before each step, the target element is scrolled into view with scrollIntoView({ behavior: "smooth", block: "center" }). The tooltip only renders after the scroll animation completes (~300ms).

Theme Adaptation

The tooltip, step banner, buttons, and spotlight border all adapt to the active theme's CSS variables. Terminal uses IBM Plex Mono, Canvas uses light colors, Studio uses glass blur.

Accessibility

role="dialog" with aria-label. Focus trapped to Back/Next/Skip. Escape key skips the tour. Respects prefers-reduced-motion (instant transitions). Screen reader announces step changes via live region.
