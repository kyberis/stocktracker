B Voice & Language

Friendly, approachable, jargon-free — like explaining stocks to a friend. Tagline: "Your portfolio. Understood."

Short & benefit-first

Lead with what the user gets, not what the system does. Use short sentences.

No jargon in primary UI

Avoid "CAGR", "alpha", "Sharpe ratio", "P/E" in headlines. OK in Pro tools with tooltips.

Active voice, second person

"Your portfolio gained 4.2%" — not "A gain of 4.2% was recorded."

No hardcoded strings

Every user-facing string through i18n. 35 languages supported. English + Spanish minimum.

Locale-aware numbers

Always use formatCurrency and formatPercent. Never hardcode currency symbols.

Emoji policy

Never in data cells, tables, or financial figures. Sparingly in onboarding and empty states.

Color Rules

Always pair dark variants

Every text-X needs a dark:text-Y pair for backgrounds, text, and borders.

Never color alone

Gain/loss must include an arrow, +/− sign, or icon alongside the color.

Soft dark backgrounds

Use dark:bg-{color}-500/10 not dark:bg-{color}-900.

Icon Rules

Icon-only buttons

Must always include aria-label for screen readers.

Decorative icons

Use aria-hidden="true" so screen readers skip them.

Use currentColor

Prefer stroke="currentColor" so icons inherit text color and respect themes.

I Accessibility Baseline

WCAG 2.1 AA minimum on all user-facing surfaces. Full review process in the accessibility-reviewer skill.

🔍 Text Contrast

4.5:1 minimum for normal text. 3:1 for large text (≥18px bold or ≥24px). Test both themes independently.

⌨ Focus Indicators

Visible on all interactive elements. Use focus-visible:ring-2 focus-visible:ring-emerald-500. Never outline-none without replacement.

↹ Keyboard Navigation

All interactive elements via Tab/Shift+Tab/Enter/Space/Escape. Modals trap focus. Return focus to trigger on dismiss.

💬 Screen Readers

All images have alt text. Dynamic content uses aria-live regions. Route changes announce page title.

🎨 Color Independence

Never use color as sole indicator. Gain/loss always includes +/− or arrow icons alongside color.

📱 Touch Targets

Minimum 44×44px on mobile. Content usable at 200% zoom without horizontal scroll. Never disable pinch-to-zoom.

⏯ Motion

Respect prefers-reduced-motion. All animations disabled when user opts out. No flashing >3 times/second.
