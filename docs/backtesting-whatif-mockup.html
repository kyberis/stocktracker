Mockup Annotations — Implementation Notes

  • Three modes — Backtest (historical "what if I had invested X"), What-If (modify current portfolio and project), Stress Test (historical crisis simulation). Each mode is a separate panel within the same tool tab.
  • Backtest — Uses existing historical data API (`/api/historical`) for price series. Up to 30 years via Yahoo Finance. DCA simulation with monthly contributions. Benchmark comparison reuses `normalizeSeries` from PortfolioBenchmarkChart. Key metrics: CAGR, max drawdown, Sharpe, dividend income.
  • What-If simulator — Pre-loads current portfolio. User edits share counts inline, adds/removes holdings. Diff badges show changes. Runs growth projection (reuses PortfolioProjection logic). Compares current vs scenario side-by-side. Surfaces sector concentration, dividend yield, and risk changes.
  • Stress Test — Pre-built crisis scenarios (GFC 2008, COVID, dot-com, 2022 rate hike, Euro debt). Uses sector-level historical drawdowns applied to current holdings. Custom scenario lets users define per-sector drawdowns. Holding-by-holding impact table shows which stocks are most vulnerable. Resilience score is a composite of diversification + sector correlation.
  • Pro-gated (Trefolio) — Full feature behind Trefolio paywall. Free users see blurred preview with benefit-oriented CTA. Matches existing ProCompareCard pattern.
  • New tool tab — Appears as "Simulator" in the Tools nav, between "Tax" and the existing tabs. Uses existing tab routing (`/tools/simulator`).
  • Reuses existing infra — Historical data API, `convertToEUR`, `calculateTTWROR`, `calculateMaxDrawdown`, `calculateSharpeRatio`, `normalizeSeries`, `closeOnOrBeforeDate`, `formatCurrency`. No new backend APIs needed for phase 1 (client-side calculations).
  • Share results — Backtest results can be shared via portfolio sharing (existing feature). Generates a shareable link with parameters encoded.
  • Responsive — Scenario table hides change column on mobile. Crisis cards stack vertically. Stats grid collapses to 2 columns.
  • Data disclaimer — "Historical performance does not guarantee future results" disclaimer shown on all result panels (legal compliance).

Phased Rollout

  • Phase 1 (v1.30) — Historical Backtest with single-asset + benchmark comparison. DCA simulation. Key metrics (CAGR, drawdown, Sharpe). Client-side calculations using existing APIs.
  • Phase 2 (v1.31) — What-If Simulator. Pre-load current portfolio, inline editing, growth projection comparison. Sector concentration + risk analysis.
  • Phase 3 (v1.32) — Stress Test. Pre-built crisis scenarios with sector-level drawdowns. Holding impact table. Resilience score. Custom scenarios.
