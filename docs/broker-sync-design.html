03 Privacy & Trust Messaging

Shown above the "Connect Broker" button on the SnapTrade tab. Clearly communicates that trefolio never sees credentials and only has read-only access.

Import → Broker Sync — Before Connect
Your credentials are never shared with trefolio
SnapTrade handles authentication
You log in directly through SnapTrade, a regulated financial data provider. trefolio never sees your broker username or password.
Encrypted credentials stored by Plaid
Your encrypted login is stored by Plaid, a banking-grade infrastructure provider used by thousands of financial apps. SnapTrade and trefolio do not store your passwords.
Read-only access — we cannot trade or move funds
We only request permission to view your holdings and transaction history. trefolio cannot execute trades, transfer money, or modify your brokerage account in any way.
Powered by SnapTrade · Bank-grade encryption · SOC 2 compliant
Design rationale: Three trust points with check icons mirror the pattern Snowball Analytics uses ("Your information will remain secure and will never be shared with anyone, including us"). Each point addresses a specific fear: (1) "Who sees my login?" → SnapTrade, not us. (2) "Where is it stored?" → Plaid, encrypted. (3) "Can they trade?" → Read-only, impossible. The green shield + green checks create an immediate "safe" signal.

Shows sync status on the dashboard (subtle) and the import page (detailed). Syncs every 6 hours automatically.

Dashboard placement: Small green pulse dot + "Synced 2h ago" in the portfolio summary card. Non-intrusive, confirms data is fresh. Shows broker names so users know which accounts are connected. Clicking navigates to the import page Broker Sync tab.

Import Page — Detailed Sync Bar

Import → Broker Sync — Sync Bar Detail
Auto-sync active · Last synced Mar 11 at 12:00 UTC (2h ago) · Next sync at ~18:00 UTC (~4h)
Frequency: Every 6 hours (00:00, 06:00, 12:00, 18:00 UTC). Covers European pre-market (06:00), mid-day (12:00), post-close (18:00), and overnight (00:00). "Sync Now" triggers an immediate manual refresh. The cron iterates all active snaptrade_connections, calls the SnapTrade refresh endpoint, fetches new activities, and deduplicates.

A temporary error occurred while fetching your latest transactions. This usually resolves on its own. The next automatic sync will retry in ~4 hours.

Error hierarchy: (1) Expired credentials (amber) — user action required, shows on both dashboard and import page. (2) Sync failure (red) — temporary, import page only, auto-retries on next cron cycle. Expired credentials block all syncing; sync failures are transient and resolve automatically.
